# Data Storytellers — Make Data Speak

Classroom game for Mr. Lee, 6th grade Technology, Kingdom Collegiate Academy.
Week 11 (October 26–30, 2026). Quarter 1, Unit 1, Computational Thinking.

**No proof, no publish.**

## Open the game

Download [index.html](index.html) and open it in Chrome. One file. No install.
Names stay on the Chromebook. Nothing is uploaded.

Headphones on for the mission. The chart plays a note for each bar, and week 7’s dip is the low note.

## Two modes

- **Class round — big screen:** tomato harvest. Do this together in guided practice. It does not reveal the student answers.
- **Start my mission:** coding-club sign-ins. Independent work. Clean, chart, type a conclusion, underline the proof, build a 30-second story, redesign the chart for a 2nd grader.

Fast finishers take the half-data test. The badge prints as a Data Story Card.

## Teacher key

On the title screen, choose Teacher and type `westgps`.

Chant: COUNT IT! CHART IT! TELL IT!
